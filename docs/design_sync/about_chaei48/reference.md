# About 정렬 (채이님 사본 19:47판, chaei48) — 지용님용 명세

채이님 사본에서 About만 바뀐 부분이다. 값만 옮긴 것이니 대회판 About(통합본 integ-1915)의 구조에 맞춰 적용한다. About 문구와 상단 띠(30%)는 그대로 둔다.

## 1. 좌우 여백 하나로
- 좌우 여백 = **4vw를 정수 px로 반올림한 값** 하나(`round(4vw, 1px)`, 지원 안 되면 4vw).
- 상단 띠와 아래 스크롤 칸 모두 같은 좌우 여백을 쓴다. 띠 제목 왼쪽 선과 본문 왼쪽 선이 같은 세로선.

## 2. 선 색·굵기 하나로
- 모든 구분선, 카드 테두리, 표 행 선 = **1px solid rgba(255,255,255,.08)**.
- 띠 아래 선, 각 구역 위 선(첫 구역은 선 없음), 접이식 참고자료 테두리, 꼬리말 위 선 모두 같은 값.

## 3. 구역 배치 (2단, 정수 px)
- 각 구역 = 2열 그리드: 왼쪽 열 **(전체 폭 / 3 − 16px, 정수 px로 내림)**, 오른쪽 열 나머지, **열 간격 24px**.
- 구역 제목(h2)은 왼쪽 열, 내용은 오른쪽 열. 마지막 CTA 구역도 같은 규칙.

## 4. 글자 규칙 (같은 역할 = 같은 규칙, 줄 높이 정수 px)
| 역할 | 값 |
|---|---|
| 구역 제목 h2 | 30px / 600 / 줄 높이 44px / margin 0 |
| 본문 문단 | 줄 높이 25px |
| 강조 문단 | 줄 높이 28px |
| 카드 제목 h3 | 줄 높이 22px |
| 카드 본문 | 줄 높이 22px |
| 표 머리 th | 줄 높이 16px |
| 표 칸 td | 줄 높이 22px |
| 숫자 카드 큰 숫자 | 줄 높이 31px, 아래 설명 18px |
| 작은 번호 라벨 | 줄 높이 14px |
| 크레딧 줄 | 줄 높이 21px |
| 접이식 제목 summary | 줄 높이 22px |
| 한계 목록 li | 줄 높이 22px |

## 5. 카드 높이 같게
- 단계 카드, 질문 카드, 숫자 카드 줄: 같은 줄의 카드 높이를 같게(stretch, 카드는 세로 flex, height 100%).
- 카드 안 아이콘·제목·본문이 같은 줄에서 시작(위 정렬).
