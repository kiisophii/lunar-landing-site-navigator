# 착륙지 검증 화면 정리 — Jiyong

텍스트 명세 기준 구현. 기존 분석의 읽는 순서를 정리하고 개발용 표시만 제거했습니다. 계산·데이터·입력 이벤트는 유지했습니다.

## 변경한 기존 영역

| 영역 | 화면 변경 | 보존한 내용 |
|---|---|---|
| 햇빛·지구 보임 시간 | 전체 폭, 읽기 쉬운 주요 수치, 해/지구/함께의 공통 시간축 | 실제 시간 구간, 분석 기간·단절 설명, 원자료 펼침, 장기 가시 구간·통계 |
| 주변 위치 민감도 | 등록 지점 수·최근접 지점·비교 표를 지도보다 먼저, PGDA 범위 막대 | 기존 지도·격자, hover/클릭·키보드 조작, 불확실성 표·범위 통계, 각각의 분석 기간 |
| 착륙 날짜·일정 지연 | 주요 수치를 크게, 날짜 표·그래프를 카드 폭에 맞게 | 착륙일·체류 기간, 날짜 훑기, 지연 비교, 다른 착륙지 선택 |
| 중계탑 효과 | 4개 주요 결과와 직접/탑 경유/비가시 시간축 정리 | 높이 선택, 여러 탑의 네트워크·지도·표, 프레넬 값, 추정 링크 버짓 결과·미검증 표시 |
| 지상국 가시 시간 | 합계 막대라는 점을 명시하고 실제 시간표와 구별 | 지상국별 시간, 착륙지 지구 가시 조건, 한국 시간, ShadowCam·한국 탑재체 공식 자료 |
| 지평선·차폐 원인 | 현재 고도·차폐 상태를 그래프 앞에, 각도·방위 기준 설명 | 같은 좌표계, 선택 시각 연동, 착륙지 선택·배율·hover |

최대 본문 폭 1392px, 좌우 최소 24px, 카드 간격 16px. 시간 분석은 전체 폭, 나머지 기존 카드는 2열이며 1100px 미만은 1열입니다. 선택 해제하면 다음 카드가 빈 칸을 채웁니다. 경사·과학 목표·이력·경로·계절 영역은 전체 폭을 사용합니다. 넓은 표는 카드 안에서 가로 스크롤하며 수치·열을 자르지 않습니다.

## 제거한 문구 / 남긴 설명

- 내부 데이터·스크립트 경로, 파일 목록, 명령줄 옵션, 원시 JSON·매개변수 키, 팀의 운영진 확인 질문, `reference_only` 내부 표기를 개별 표시 위치에서 정리했습니다. 확장자에 따른 일괄 삭제는 하지 않았습니다.
- 관측 높이·표본 간격·지형 해상도 및 자세한 중계탑 가정은 기존 계산 방법 영역에 유지했습니다. 링크 버짓 매개변수는 이름·단위를 붙인 별도 계산 방법 펼침으로 표시하며 **결과 표는 그대로 펼쳐져 있습니다**.
- 기관·데이터셋 이름, 공식 외부 링크, 추정/미검증/자료 부족, 기간 경계에서 잘리는 통계, PSR≠확인된 얼음, 기하학적 가시성≠실제 통신 성능을 유지했습니다.
- 기존 과학 데이터셋 이름(예: LPSR_80S_20MPP_ADJ)은 출처이므로 남깁니다. DSN_34m / KDSA_35m은 사용자용 표기 DSN 34m / KDSA 35m으로만 바꿨습니다.

## 보존한 추가 기능

- 경사·거칠기·평탄 비율과 원래의 8°/15° 참고 기준
- PSR 접근성, 거리·방위·범위 밖/불완전 자료 안내
- 주변 착륙 이력과 공식 임무 링크
- 경로·장애물 지표 및 ‘실제 경로 계획이 아님’ 설명
- 계절 분석, 월/달의 하루 선택과 월 클릭
- 기존 카드 안의 2026–2030 장기 통계·가시 구간, 원자료, 주변 지도·격자·불확실성, 착륙일/체류/지연/대안 후보, 여러 중계탑·링크 버짓, 지상국 KST 시간표·ShadowCam
